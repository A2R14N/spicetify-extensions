# Spicetify Extensions

Extensions for the Spotify desktop client, made by [A2R14N](https://github.com/A2R14N).

## Plinko Volume

Replace the volume slider with a Plinko game. Drop a ball to choose your volume, and see the current percentage beside the Plinko button.

![Plinko Volume](gamblevolume/preview.png)

[Features and installation](gamblevolume/README.md)

## Installation

Install **Plinko Volume** from Spicetify Marketplace and reload Spotify. Open your profile menu, choose **Plinko Volume Settings**, enable the extension, and save.

For manual installation, follow the [extension's instructions](gamblevolume/README.md#manual-installation).

Requires [Spicetify](https://spicetify.app/) and the Spotify desktop client.
